<h1 align="left">Foco em Segurança de Dados & Web</h1>

* 🔒 **Validação e Sanitização de Entradas:** Prevenção de vulnerabilidades comuns como **SQL Injection** e **Cross-Site Scripting (XSS)** no backend (PHP / MySQL).
* 🔑 **Autenticação & Controlo de Acesso:** Implementação de mecanismos seguros de sessões, encriptação de palavras-passe (hashing) e gestão de permissões.
* 🛡️ **Privacidade & Comunicação Segura:** Proteção do tráfego de dados no consumo de **APIs REST** e aplicação de princípios de proteção de dados pessoais (RGPD).
